## Порядок и границы

В начале первой сессии дождаться освобождения `run.lock` серии зависимостей
в её каталоге состояния под `~/t/scratch` и проверить её CURRENT/финал:
живой ход в демоне после смерти раннера тоже должен закончиться.
Ожидание внутри текущего хода, с опросом фоновой команды; не завершать ход
ради ожидания и не расходовать на него следующие сессии. Не менять код,
манифесты и планы другой серии во время ожидания.
После остановки зависимостей прочитать `PLAN_dependencies_2026-10-21.md`:
при незавершённой миграции учитывать ограничения и делать независимую работу.
Серию зависимостей самостоятельно не перезапускать.

Прочитать локальный skill code-smell и README установленного инструмента.
Порядок: scoped MCP health/audit → clippy → code_smell, первой командой
суиты — `stats`. Проверять фактический каталог, включая egui и доступные
compiler/semantic движки. Детектор с требованием политики не выдавать за
успешно пройденный при отсутствии секции; exit 2 и unresolved — отказ/ограничение.
До семантического поиска использовать rust-code-mcp по правилам CLAUDE.
Не добавлять произвольные allowlist ради чистого отчёта. Настраивать политику
только по реальным доменам проекта, с объяснением каждого исключения.

Сохранить исходный вывод вне git в состоянии серии; итог оценивать по дельте.
Счётчик — сигнал к разбору, не цель. Подтверждать пользу исправления и отличать
FP (trait signatures, осознанные численные clamps, domain bundles и т.д.).
Сохранять locked-решения `docs/note_detection.md` §7 и памяти проекта.
Не менять DSP-поведение, численные эталоны, продуктовые решения или старые
форматы только ради smell. H3/H7 и снос ремонтного слоя ждут Стаса;
новые настройки и переключатели в рамках этой серии не добавлять.

Проверки по затронутому коду: desktop clippy/подходящие тесты, web
`cargo check --target wasm32-unknown-unknown --lib --bins`, Android
`cargo check --target aarch64-linux-android --lib`; rustdoc при изменении API.
Для UI-интеракции пользоваться существующим egui_kittest, не выдавать
state-тест за проверку проводки ввода. Не запускать рабочее окно Стаса.
Форматировать только изменённые файлы; коммитить свои пути, не пушить.
Вложенные серии и субагенты не нужны. Независимые находки вне скоупа — сюда
с адресом и причиной, а не попутный рефактор без границы.
