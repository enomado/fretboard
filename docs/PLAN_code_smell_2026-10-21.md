# Code smells fretboard: перенесено в единый трек

По уточнению Стаса «в одном треке» отдельная серия
`fretboard-code-smell` остановлена до начала анализа и правок кода.

Все восемь областей code smell, правила проверки и актуальный хендоф
перенесены в [единую очередь зависимостей и рефактора](PLAN_dependencies_2026-10-21.md).
Серия `fretboard-deps` выполняет её строго последовательно: сначала
обновление и проверка зависимостей, затем code smells. Общий лимит — 14 сессий.
Этот файл не является отдельной очередью и не требует возобновления серии.
